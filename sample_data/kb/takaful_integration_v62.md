# Takaful Integration Note v6.2

> SAMPLE CONTENT: synthetic, not real Azentio data. Fictional product for demonstration only.

Document date: 2026-02-10 | Product version: 6.2

## 1. Position

MIBS does not include a native Takaful policy administration system.

## 2. Integration

Takaful on financed assets is supported through API integration with the customer's Takaful operator system. MIBS stores the policy reference and can block disbursement until a valid Takaful certificate reference is attached to the financing case. Premium, coverage and beneficiary data remain in the operator's system.
