# Extensions, Workflows and Reporting 2026

> LIVE TEST CONTENT: synthetic. Fictional product and companies, for testing only.

Document date: 2026-09-10 | Product version: 6.2

## 1. Benchmark rates

Profit-rate benchmarking against an external index is not delivered as standard. It is available as a customer-specific extension built on the Pricing API by Safa Systems professional services. The effort depends on the index provider.

## 2. Approval workflows

Approval workflows are configured for each product by the bank's administrators. No code change is needed.

## 3. Reporting

A standard set of 40 operational and regulatory reports is included. Additional reports are produced with the configurable report designer.

## 4. Takaful

Takaful on financed assets is supported through API integration with the customer's Takaful operator. Premium, coverage and beneficiary data remain in the operator's system.
